# 🚀 网页图书PDF化工具 - 快速开始

## 📦 一键启动（推荐）

1. **解压文件夹到任意位置**
2. **右键点击文件夹空白处 → "在终端中打开"**
3. **执行启动脚本**：
   ```powershell
   .\启动脚本.ps1
   ```
4. **按照屏幕提示操作**

## 🎯 使用流程

### 第一步：程序启动
- 脚本会自动启动Chrome和控制程序
- 看到菜单后，选择操作模式

### 第二步：准备网页
- 在Chrome中打开图书网站
- 登录并找到要截图的书籍
- **重要**：调整页面缩放到67%

### 第三步：开始截图
- 回到终端，输入 `2` 选择自动化批量截图
- 第一次会让你框选书籍区域
- 程序自动截图20页并翻页
- 完成后可以继续下一批次或合并PDF

## 🔧 手动启动（备用方法）

如果一键启动失败，可以手动执行：

```powershell
# 1. 关闭Chrome
Get-Process chrome -ErrorAction SilentlyContinue | Stop-Process -Force

# 2. 启动Chrome调试模式
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir=".\temp_chrome_debug"

# 3. 启动控制程序（新开PowerShell窗口）
python cli.py browser --connect-existing --debug-port 9222 --start-url blank --viewport-w 1600 --viewport-h 1200
```

## ❓ 常见问题

**Q: 找不到Chrome？**
A: 修改启动脚本中的Chrome路径，或安装Chrome浏览器

**Q: 端口被占用？**
A: 重启电脑或修改端口号为9223

**Q: 截图质量差？**
A: 调整浏览器缩放比例到67%

**Q: 翻页失败？**
A: 检查网页是否支持键盘右键翻页
