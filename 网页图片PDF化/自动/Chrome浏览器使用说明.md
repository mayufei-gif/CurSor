# 🎉 Chrome浏览器使用说明

## ✅ 问题已解决！

您的网页截图PDF生成器现在可以正常使用Chrome浏览器了！

## 🚀 如何使用

### 1. 启动程序
程序已经在运行中，您应该能看到图形界面窗口。

### 2. 选择浏览器引擎
- 在"浏览器"下拉菜单中，选择 **"selenium"**
- 这将使用Chrome浏览器进行网页截图

### 3. 输入网页URL
- 在"网页URL"输入框中输入您要截图的网址
- 例如：`https://www.baidu.com` 或 `https://www.github.com`

### 4. 配置选项
- ✅ **全页面截图**：勾选此选项可以截取整个网页
- ✅ **启用OCR**：勾选此选项可以识别图片中的文字
- **窗口大小**：默认1920×1080，可以根据需要调整
- **等待时间**：页面加载等待时间，默认3秒
- **OCR引擎**：选择"auto"会自动选择最佳引擎

### 5. 开始处理
- 点击"开始处理"按钮
- 程序会自动：
  1. 启动Chrome浏览器
  2. 访问指定网页
  3. 等待页面加载完成
  4. 截取网页截图
  5. 进行OCR文字识别（如果启用）
  6. 生成PDF文件

### 6. 查看结果
- 处理完成后，会显示成功消息
- PDF文件会保存到您指定的位置
- 默认文件名：`screenshot.pdf`
