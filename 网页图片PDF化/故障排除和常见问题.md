# 故障排除和常见问题解答

## 🚨 紧急故障处理

### 程序完全无法启动
```powershell
# 1. 重置所有进程
Get-Process chrome -ErrorAction SilentlyContinue | Stop-Process -Force
Get-Process python -ErrorAction SilentlyContinue | Stop-Process -Force

# 2. 清理端口
netstat -ano | findstr :9222
# 如果有占用，记录PID并终止：taskkill /PID <PID> /F

# 3. 重新启动
cd "g:\E盘\工作项目文件\AI_Agent\Trae_Abroad\网页图片PDF"
.\启动脚本.ps1
```

### 程序运行中突然中断
```powershell
# 1. 检查错误日志
Get-Content error.log -Tail 20

# 2. 检查Chrome进程状态
Get-Process chrome -ErrorAction SilentlyContinue

# 3. 重新连接（如果Chrome还在运行）
python cli.py browser --connect-existing --debug-port 9222
```

## 🔧 环境问题

### 问题1：PowerShell执行策略限制
**错误信息**：
```
无法加载文件 启动脚本.ps1，因为在此系统上禁止运行脚本
```

**解决方案**：
```powershell
# 方法1：临时允许（推荐）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 方法2：绕过策略执行
powershell -ExecutionPolicy Bypass -File "启动脚本.ps1"

# 方法3：永久设置（需要管理员权限）
Set-ExecutionPolicy RemoteSigned
```

### 问题2：Python环境问题
**错误信息**：
```
'python' 不是内部或外部命令
```

**解决方案**：
```powershell
# 1. 检查Python安装
where python
where python3

# 2. 如果未安装，下载安装Python 3.8+
# 3. 添加到PATH环境变量
$env:PATH += ";C:\Python39;C:\Python39\Scripts"

# 4. 验证安装
python --version
pip --version
```

### 问题3：依赖包缺失
**错误信息**：
```

```

**解决方案**：
```powershell

# 2. 安装所有依赖
```

## 🌐 Chrome浏览器问题

### 问题4：Chrome启动失败
**错误信息**：
```
无法启动Chrome调试模式
```

**解决方案**：
```powershell
# 1. 检查Chrome安装路径
$chromePaths = @(
    "C:\Program Files\Google\Chrome\Application\chrome.exe",
    "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe",
    "$env:LOCALAPPDATA\Google\Chrome\Application\chrome.exe"
)

foreach ($path in $chromePaths) {
    if (Test-Path $path) {
        Write-Host "找到Chrome: $path"
        $chromePath = $path
        break
    }
}

# 2. 手动启动Chrome
Start-Process $chromePath -ArgumentList "--remote-debugging-port=9222", "--user-data-dir=.chrome_profiles\IA"
```

## 📊 诊断工具

### 系统信息收集脚本
```powershell
# 创建诊断报告
$report = @"
=== 系统诊断报告 ===
时间: $(Get-Date)
操作系统: $(Get-WmiObject Win32_OperatingSystem | Select-Object -ExpandProperty Caption)
PowerShell版本: $($PSVersionTable.PSVersion)
Python版本: $(python --version 2>&1)
Chrome进程: $(Get-Process chrome -ErrorAction SilentlyContinue | Measure-Object | Select-Object -ExpandProperty Count)
可用内存: $([math]::Round((Get-WmiObject Win32_OperatingSystem).FreePhysicalMemory/1MB, 2)) GB
磁盘空间: $(Get-WmiObject Win32_LogicalDisk | Where-Object {$_.DeviceID -eq "G:"} | Select-Object -ExpandProperty FreeSpace)
网络连接: $(Test-NetConnection google.com -Port 80 -InformationLevel Quiet)
"@

$report | Out-File "diagnostic_report.txt"
Write-Host "诊断报告已保存到 diagnostic_report.txt"
```

### 日志分析脚本
```powershell
# 分析错误日志
function Analyze-Logs {
    $logFiles = Get-ChildItem -Path "." -Filter "*.log" -ErrorAction SilentlyContinue
    foreach ($log in $logFiles) {
        Write-Host "分析日志文件: $($log.Name)"
        $errors = Select-String -Path $log.FullName -Pattern "ERROR|FAIL|Exception" -SimpleMatch
        if ($errors) {
            Write-Host "发现错误:" -ForegroundColor Red
            $errors | ForEach-Object { Write-Host "  $($_.Line)" }
        } else {
            Write-Host "未发现错误" -ForegroundColor Green
        }
    }
}

Analyze-Logs
```
