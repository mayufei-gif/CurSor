# 🎯 网页图书PDF化工具 - 项目功能总结

## 📋 项目概述

本工具是一个专业的网页图书PDF化解决方案，支持自动化批量截图、智能区域识别、自动翻页等功能，特别适用于在线图书馆、电子书平台的内容保存。

## ✨ 核心功能

### 🚀 自动化批量截图
- **智能翻页**：使用键盘右键自动翻页
- **批次管理**：每20页为一个批次，支持连续处理
- **区域记忆**：第一次选择截图区域后，后续页面自动使用相同区域
- **质量优化**：自动放大选中区域，确保文字清晰可读

### 📸 智能截图技术
- **交互式区域选择**：可视化框选书籍内容区域
- **自动缩放计算**：智能计算最佳放大比例
- **高质量输出**：支持高分辨率截图，文字清晰
- **容错机制**：截图失败时自动回退到备用方案

### 📁 文件管理系统
- **自动命名**：按顺序命名图片文件（page_001.png, page_002.png...）
- **目录组织**：按批次和时间戳创建文件夹
- **PDF生成**：自动将图片合并为PDF文件
- **批次合并**：支持将多个批次合并为完整PDF

### 🔧 浏览器集成
- **Chrome调试模式**：连接到现有Chrome实例
- **状态保持**：复用浏览器登录状态
- **视口控制**：自动设置最佳浏览器窗口大小
- **页面控制**：支持JavaScript操作和键盘模拟

## 🎛️ 操作模式

### 模式1：单页截图
- 适用于少量页面或测试
- 手动选择每个页面
- 支持自定义文件名

### 模式2：自动化批量截图（推荐）
- 适用于大量页面处理
- 自动翻页和截图
- 批次化管理
- 支持中途暂停和继续

## 📁 输出规格

### 文件结构
```
输出目录/
├── 书籍/
│   ├── 原图/                    # PNG格式原始截图
│   │   ├── batch_01_20250115_143022/
│   │   │   ├── page_001.png    # 1600x1200分辨率
│   │   │   ├── page_002.png
│   │   │   └── ...
│   │   └── batch_02_20250115_144530/
│   └── PDF涂书/                 # PDF格式文件
│       ├── batch_01_20250115_143022.pdf
│       ├── batch_02_20250115_144530.pdf
│       └── complete_book_20250115_150000.pdf
└── 论文/
    └── OCRmyPDF/               # OCR处理后的可搜索PDF
        └── complete_book_ocr_20250115_150000.pdf
```

### 文件规格
- **图片格式**：PNG（无损压缩）
- **图片分辨率**：1600x1200（可配置）
- **PDF质量**：高质量，适合打印
- **OCR支持**：中英文混合识别

## 🔄 工作流程

### 标准流程
1. **环境准备**：启动Chrome调试模式
2. **程序连接**：连接到Chrome实例
3. **网页准备**：登录网站，调整页面
4. **区域选择**：框选书籍内容区域
5. **批量截图**：自动截图和翻页
6. **文件生成**：生成PDF和OCR文件

### 高级流程
1. **多批次处理**：分批处理大型图书
2. **质量检查**：检查截图质量
3. **区域调整**：根据需要调整截图区域
4. **文件合并**：合并多个批次
5. **OCR处理**：生成可搜索PDF
