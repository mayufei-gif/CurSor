# 一键启动脚本使用说明

## 🚀 快速开始

### 最简单的启动方式

1. **打开PowerShell**
   ```powershell
   # 在项目文件夹中右键 -> "在此处打开PowerShell窗口"
   # 或者按 Win+R，输入 powershell，然后cd到项目目录
   ```

2. **执行一键启动脚本**

## 🛠️ 故障排除

### 执行策略问题
如果遇到"无法加载文件，因为在此系统上禁止运行脚本"错误：

```powershell
# 临时允许脚本执行
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后重新运行脚本
.\启动脚本.ps1
```

### Chrome路径问题
如果脚本找不到Chrome，手动指定路径：

```powershell
# 编辑启动脚本.ps1，修改Chrome路径
$chromePaths = @(
    "C:\Program Files\Google\Chrome\Application\chrome.exe",
    "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe",
    "你的Chrome安装路径\chrome.exe"  # 添加自定义路径
)
```

### 端口占用问题
如果9222端口被占用：

```powershell
# 检查端口占用
netstat -ano | findstr :9222

# 终止占用进程
taskkill /PID <进程ID> /F

# 或者修改脚本使用其他端口
$debugPort = 9223
```

### Python环境问题
如果Python环境有问题：

```powershell
# 检查Python版本
python --version

# 检查虚拟环境
.\.venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt
```

### 手动启动命令参考
```powershell
# 1. 切换目录
cd "g:\E盘\工作项目文件\AI_Agent\Trae_Abroad\网页图片PDF"

# 2. 关闭Chrome
Get-Process chrome -ErrorAction SilentlyContinue | Stop-Process -Force

# 3. 等待
Start-Sleep -Seconds 2

# 4. 启动Chrome
Start-Process "chrome.exe" -ArgumentList "--remote-debugging-port=9222", "--user-data-dir=.chrome_profiles\IA"

# 5. 等待
Start-Sleep -Seconds 3

# 6. 验证连接
Invoke-WebRequest -Uri "http://localhost:9222/json" -UseBasicParsing

# 7. 启动程序
python cli.py browser --connect-existing --debug-port 9222 --start-url blank --viewport-w 1600 --viewport-h 1200
```

## 📝 使用技巧

### 技巧1：创建桌面快捷方式
```powershell
# 创建快捷方式到桌面
$WshShell = New-Object -comObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut("$Home\Desktop\网页图书PDF化.lnk")
$Shortcut.TargetPath = "powershell.exe"
$Shortcut.Arguments = "-ExecutionPolicy Bypass -File `"g:\E盘\工作项目文件\AI_Agent\Trae_Abroad\网页图片PDF\启动脚本.ps1`""
$Shortcut.WorkingDirectory = "g:\E盘\工作项目文件\AI_Agent\Trae_Abroad\网页图片PDF"
$Shortcut.Save()
```

### 技巧2：添加到右键菜单
1. 打开注册表编辑器 (regedit)
2. 导航到 `HKEY_CLASSES_ROOT\Directory\Background\shell`
3. 创建新项 "网页图书PDF化"
4. 在该项下创建 "command" 子项
5. 设置默认值为脚本路径

### 技巧3：定时任务
```powershell
# 创建定时任务（可选）
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-File `"g:\E盘\工作项目文件\AI_Agent\Trae_Abroad\网页图片PDF\启动脚本.ps1`""
$trigger = New-ScheduledTaskTrigger -Daily -At "09:00"
Register-ScheduledTask -Action $action -Trigger $trigger -TaskName "网页图书PDF化" -Description "自动启动网页图书PDF化工具"
```

## 🔧 高级配置

### 配置文件模板
创建 `config.ps1` 文件进行个性化配置：

```powershell
# config.ps1
$Global:Config = @{
    DebugPort = 9222
    UserDataDir = ".chrome_profiles\IA"
    ViewportWidth = 1600
    ViewportHeight = 1200
    StartUrl = "blank"
    WaitTime = 3
    MaxRetries = 3
}
```

### 日志记录
启用详细日志记录：

```powershell
# 在启动脚本.ps1中添加
$logFile = "startup_log_$(Get-Date -Format 'yyyyMMdd_HHmmss').txt"
Start-Transcript -Path $logFile
# ... 脚本内容 ...
Stop-Transcript
```
